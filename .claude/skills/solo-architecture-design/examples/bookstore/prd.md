# PRD：オンライン書店（記入例）

- 状態：合意済み

## 1. 背景と課題
小さな出版社が、自社の本を直販できる場所がない。大手ECは手数料が高く、在庫の反映も遅い。

## 2. 対象ユーザー
| 役割 | 説明 | 主な目的 |
|---|---|---|
| ユーザー | 本を買う一般の読者 | 本を探して注文する |
| 出版社 | 本を登録する事業者 | 本を掲載し、売れ行きを見る |
| 書店運営者 | このサービスの運営者（自分） | 在庫と注文を管理する |

## 3. 要件
| ID | 要件 | 優先度 |
|---|---|---|
| R1 | 出版社は本を登録・更新・販売終了にできる | Must |
| R2 | 書店運営者は本ごとの在庫数を管理できる | Must |
| R3 | ユーザーは本を検索し、在庫のある本を注文できる | Must |
| R4 | ユーザーはカード決済で支払える | Must |
| R5 | 注文が確定すると、配送サービスに発送が依頼される | Must |
| R6 | ユーザーは自分の注文履歴を見られる | Should |

## 4. やらないこと
- 電子書籍の販売
- 複数の倉庫・店舗の在庫管理（在庫拠点は1つ）
- ポイント・クーポン
- 自前の決済処理（決済は外部サービスに任せる）

## 5. 成功の指標
- 注文完了率 70%以上（カート投入から）
- 在庫切れの本が注文されてしまう件数 0件

## 6. 名詞と動詞
| 要件ID | 名詞 | 動詞 |
|---|---|---|
| R1 | 出版社、本 | 登録する、更新する、販売終了にする |
| R2 | 在庫 | 管理する（増減する） |
| R3 | ユーザー、本、注文 | 検索する、注文する |
| R4 | 決済 | 支払う |
| R5 | 発送 | 依頼する |
| R6 | 注文 | 一覧する |

## 7. 制約
- 期限：3か月で公開
- 予算：月額 5,000円以内
- 使う技術：TypeScript（フロント・バック共通）
