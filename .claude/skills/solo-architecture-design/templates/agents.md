# AGENTS.md

このリポジトリで作業するAIコーディングエージェント向けのルール。
設計の正は `docs/design.md`、API契約の正は `docs/api/`。これらと矛盾する実装をしない。

## 作業の原則
- 担当範囲（作業指示書に書かれたコンポーネント）以外のファイルを変更しない
- API契約にない入出力・エラー・デフォルト値を勝手に追加しない。必要なら作業を止めて質問する
- 他コンポーネントの内部（DB・非公開の関数）を直接使わない。公開されたAPI（入口）だけを使う
- 仕様が不明なときは推測で埋めず、`QUESTIONS:` として最後にまとめて報告する

## ディレクトリ構成
```
src/
  modules/<コンポーネント名>/
    index.ts        … 公開する入口（他モジュールはここだけをimportする）
    domain/         … 業務ルール・型（他の層をimportしない）
    application/    … ユースケース
    infrastructure/ … DB・外部APIの実装
docs/
  design.md
  api/openapi.yaml
  adr/
```
